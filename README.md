## About Web Amy Valorant

Web Amy Valorant is a browser-based game script utility intended for Valorant-related workflows in a web environment. Its design emphasizes lightweight automation, straightforward controls, and interface tools for organizing routine training or gameplay actions without installing a separate application.

The utility uses HTML and JavaScript, while browser-local storage handles user preferences. This provides a quick way to open the tool, configure controls, and return to saved settings, with hotkeys and visible state information available from the interface.
